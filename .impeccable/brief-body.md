# Surface brief: portfolio home (index.html)

Scope: the whole single-page portfolio plus its project dossier overlay. Visitor mode: Experience. Audience: game-studio recruiters and leads skimming for a minute. Job: see shipped games moving, open one, reach resume or contact.

## Direction contract

THESIS: The portfolio is a fighting-game character select screen; every project is a selectable fighter whose footage steps onto the stage. Refuses the category default of a dark neon dev portfolio with a headline hero and a grid of equal cards.

OWN-WORLD: Saturated cobalt field (#2430E6) owning most of the page, deep ink (#0E0C2B) stage, P1 red (#F23A2E) for selection and primary action, ready yellow (#FFC93C) for focus and highlights, cream (#FFF6E0) type. One diagonal angle (-8deg) cuts every panel, tile, and wipe. Condensed heavy display (Big Shoulders Display) for names and headings, Rubik for reading text.

STORY: A recruiter lands on the select screen, sees a production game already playing, scans the roster, previews others by hover or focus, opens one into a dossier with all footage and build notes, then grabs the resume or emails from the always-present HUD.

FIRST VIEWPORT: Top HUD bar: portrait chip, Francis Yambao, game developer, section links, red Resume button and Contact. Left 60%: slanted stage with the selected project's footage, its name in huge condensed caps, its kicker, a fixed stat strip (engine, platform, footage), and an Open button as the primary action. Right 40%: intro heading with one-sentence pitch, then the 2x3 roster of slanted project tiles, selected tile flooded red.

FORM: Character Select (fighting-game roster screen), position 3 of 7 on the ordered list, seed key 7e026c11. Signature interaction: choosing a project runs one diagonal VS-splash wipe into its dossier; roster hover/focus previews on stage first. Raises: one gesture one transformation (cape); state flooded on the surface (chromatophore); preview before commit (algorave); fixed one-fact stat slots (six-pack); one diagonal angle everywhere (pulp); permanent HUD escape route (night market).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
